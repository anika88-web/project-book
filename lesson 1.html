Chapter 1: Computer System

A computer system is an electronic device that accepts raw data as input, processes it according to stored instructions, produces useful information as output, and stores it for future use.

1. Fundamental Components (Hardware)

Input Devices: Tools used to enter data into the computer.
Examples: Keyboard, Mouse, Scanner, Microphone.

Central Processing Unit (CPU): The brain of the computer that processes data.
- ALU (Arithmetic Logic Unit): Performs math calculations.
- CU (Control Unit): Directs system operations.
- Registers: High-speed storage inside CPU.

Output Devices: Tools that display processed information.
Examples: Monitor, Printer, Speaker.

Memory and Storage:
- RAM: Volatile temporary storage.
- ROM: Non-volatile permanent storage.
- Secondary Storage: Permanent storage (SSD, HDD, USB Drive).

2. Computer Software

System Software: Manages hardware (e.g., Windows, macOS, Linux).
Application Software: Performs user tasks (e.g., Web Browsers, Games).
